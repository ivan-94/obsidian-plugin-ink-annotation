# Inkstone Annotations 0.1.4

This BRAT Beta fixes intermittent Reading View annotation failures after Obsidian virtualizes a long
note or resumes from the background, with particular relevance to iPadOS app switching.

## Fixes

- Invalidate disposable DOM block bindings whenever Obsidian replaces or edits rendered blocks
  inside a retained Reading View, so a new paragraph is never resolved through detached elements
  from an older render.
- Preserve the view-level text-selection delegate when a postprocessor section disconnects during
  virtualization or backgrounding but its owning Reading View remains connected.
- Treat temporarily stale Obsidian section bounds as a hint rather than an authoritative exclusion;
  accept a wider candidate only when semantic kind, complete visible text, and monotonic view order
  still prove one unique source binding.
- Keep ambiguous and generated content fail-closed. The correction does not guess a source target
  and does not change canonical annotation data.

## Upgrade

BRAT should update the plugin from the GitHub Release automatically. To install it manually,
download `main.js`, `manifest.json`, and `styles.css` from this Release and replace the files under:

```text
<Vault>/.obsidian/plugins/inkstone-annotations/
```

For an iOS/iPadOS Vault, Obsidian may use `.obsidian-mobile/plugins/inkstone-annotations/` instead.
Reload Obsidian after the files are updated. Back up the Vault before using a Beta with important
notes.

## Compatibility and data safety

- Obsidian 1.7.2 or newer.
- Desktop and mobile manifests remain enabled.
- No Sidecar schema, annotation data migration, telemetry, or external service changes.
- Source Projection remains revision-scoped; only disposable DOM bindings are rebuilt.
- Canonical annotation data remains under `.obsidian-annotations/`.
- Disabling or uninstalling the plugin does not remove canonical Sidecars or exports.

## Known limitations

- Text annotation creation remains limited to Reading View.
- Snapshot capture remains viewport-based rather than full-document capture.
- Annotation sidebars and Ink/Snapshot editor toolbars still contain some English copy.
- Built-in style display names remain English pending the preset-label policy.

### Key decisions

- Treat Obsidian's rendered DOM as transient even when the outer Reading View identity is retained.
- Rebuild only disposable DOM bindings after host mutations; reuse unchanged Source Projection and
  preserve canonical source anchors and Sidecars.
- Retain a view-level delegate across a disconnected postprocessor section only while the owning
  Reading View remains connected.
- Continue the public `0.1.x` BRAT Beta line with minimum Obsidian version 1.7.2.
