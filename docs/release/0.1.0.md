# Inkstone Annotations 0.1.0

This is the first public Beta of Inkstone Annotations.

## Highlights

- Highlight and underline supported text in Reading View without rewriting Markdown.
- Add notes and tags, recover anchors after nearby edits, and fail closed when a target is
  ambiguous.
- Capture the visible Reading View and add Pen or Highlighter strokes to a stable image.
- Reopen, edit, preview, delete, restore, search, and export annotations from the sidebar.
- Keep canonical data inside the Vault under `.obsidian-annotations/`.

## Compatibility

- Obsidian 1.7.2 or newer.
- Desktop and mobile manifests are enabled.
- `html-to-image@1.11.13` is embedded in `main.js`; it is not loaded from a CDN.
- The capture adapter skips font downloads, inlines already-loaded Vault images, and replaces remote
  or URL-backed resources rather than refetching them.

## Install

Download `main.js`, `manifest.json`, and `styles.css` from this Release and copy them into:

```text
<Vault>/.obsidian/plugins/inkstone-annotations/
```

Reload Obsidian, then enable **Inkstone Annotations** under **Community plugins**.

Back up the Vault before using a Beta with important notes. Disabling or uninstalling the plugin
does not remove canonical sidecars or exports.

## Known limitations

- Text annotation creation is limited to Reading View.
- Snapshot captures the visible viewport, not an entire document.
- Remote images, URL backgrounds/masks, and unsupported generated content may become explicit
  placeholders.
- The task producing this release relied on the product owner's completed human acceptance and did
  not repeat HAT; it does not invent device/version/performance details that were not supplied.
- Windows, Linux, Android, physical screen-reader, and dual-device sync evidence should continue to
  be expanded during Beta.
