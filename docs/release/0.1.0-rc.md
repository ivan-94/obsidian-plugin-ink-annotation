# Inkstone Annotations 0.1.0 Release Candidate

状态：本地候选，不授权外部发布。

## 构建

```bash
npm run package:rc
```

该命令先运行完整自动门禁，再生成：

```text
dist/inkstone-annotations-0.1.0/
├── main.js
├── manifest.json
├── styles.css
└── checksums.json
```

Packager 会校验 `package.json`、`manifest.json`、`versions.json`
版本一致，并在生成后重新验证三个运行时文件的 SHA-256。候选包没有自动上传、push、GitHub
Release 或社区插件提交。

## 安装、升级、回滚验证

- Fresh install：复制三个运行时文件到空插件目录，启用后执行 S14 HAT P0。
- Upgrade：备份旧插件目录和 `.obsidian-annotations/`，覆盖运行时文件，确认 schema v1
  records 和 tombstones 可读。
- Rollback：禁用插件，恢复旧运行时文件；canonical sidecars 不应因插件文件回滚被删除。
- Uninstall：删除插件目录后 canonical sidecars 与导出仍保留。

完整人工验证前，本文件不代表发布批准。
