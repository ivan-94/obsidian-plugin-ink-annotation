# Inkstone Annotations 0.1.3

This BRAT Beta restores the text-annotation action bar when Inkstone starts with an already-open
Reading View and when a native iPad text selection changes through its drag handles.

## Fixes

- Fully rerender already-open Markdown Reading Views after Inkstone registers its annotation
  postprocessor, so their rendered sections are mounted without requiring a manual view switch.
- Observe stabilized native selection changes on mobile and open the touch action bar after the user
  finishes adjusting the selection handles.
- Keep desktop selection behavior unchanged and clean up the mobile listener and timer when the
  Reading View integration is disposed.

## Upgrade

BRAT should update the plugin from the GitHub Release automatically. To install it manually,
download `main.js`, `manifest.json`, and `styles.css` from this Release and replace the files under:

```text
<Vault>/.obsidian/plugins/inkstone-annotations/
```

For an iOS/iPadOS Vault, Obsidian may use `.obsidian-mobile/plugins/inkstone-annotations/` instead.
Reload Obsidian after the files are updated. Back up the Vault before using a Beta with important
notes.

## Compatibility and data safety

- Obsidian 1.7.2 or newer.
- Desktop and mobile manifests remain enabled.
- No Sidecar schema, annotation data migration, telemetry, or external service changes.
- Canonical annotation data remains under `.obsidian-annotations/`.
- Disabling or uninstalling the plugin does not remove canonical Sidecars or exports.

## Known limitations

- Text annotation creation remains limited to Reading View.
- Snapshot capture remains viewport-based rather than full-document capture.
- Annotation sidebars and Ink/Snapshot editor toolbars still contain some English copy.
- Built-in style display names remain English pending the preset-label policy.

### Key decisions

- Recover already-open preview views with one full Obsidian rerender after the postprocessor is
  registered, rather than duplicating the postprocessor mount path.
- Listen for document-level `selectionchange` only on mobile and debounce it for 120 milliseconds so
  native selection handles can settle before resolving the source anchor.
- Preserve canonical Sidecars and source-based anchors without a migration or persistence change.
- Continue the public `0.1.x` BRAT Beta line with minimum Obsidian version 1.7.2.
