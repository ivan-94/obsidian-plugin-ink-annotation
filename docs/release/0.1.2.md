# Inkstone Annotations 0.1.2

This BRAT Beta fixes an Entire Vault Catalog that could remain empty even though canonical
annotations were present and readable from Current file.

## Fixes

- Reconcile canonical Sidecars before serving the first Entire Vault query of each plugin session.
- Reuse the reconciled Catalog when the sidebar closes and reopens during the same plugin session.
- Make **Refresh annotation index** request canonical reconciliation instead of only repainting the
  current Catalog result.
- Preserve the existing device-local, disposable Catalog and canonical Sidecar formats without a
  migration.

## Upgrade

BRAT should update the plugin from the GitHub Release automatically. To install it manually,
download `main.js`, `manifest.json`, and `styles.css` from this Release and replace the files under:

```text
<Vault>/.obsidian/plugins/inkstone-annotations/
```

Reload Obsidian after the files are updated. The next first use of Entire Vault in that plugin
session reconciles the local Catalog from canonical Sidecars. Back up the Vault before using a Beta
with important notes.

## Compatibility and data safety

- Obsidian 1.7.2 or newer.
- Desktop and mobile manifests remain enabled.
- No Sidecar schema, annotation data migration, telemetry, or external service changes.
- The Vault Catalog remains a disposable device-local IndexedDB projection. Canonical annotation
  data remains under `.obsidian-annotations/`.
- Disabling or uninstalling the plugin does not remove canonical Sidecars or exports.

## Known limitations

- Text annotation creation remains limited to Reading View.
- Snapshot capture remains viewport-based rather than full-document capture.
- Annotation sidebars and Ink/Snapshot editor toolbars still contain some English copy.
- Built-in style display names remain English pending the preset-label policy.

### Key decisions

- Treat the Vault Catalog as disposable and repair it from canonical Sidecars; do not migrate or
  rewrite annotation data.
- Reconcile once on the first Catalog use of each plugin session, covering changes missed while the
  plugin was stopped.
- Keep manual refresh as an explicit canonical reconciliation escape hatch.
- Continue the public `0.1.x` BRAT Beta line with minimum Obsidian version 1.7.2.
