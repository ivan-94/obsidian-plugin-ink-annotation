# Inkstone Annotations 0.1.1

This BRAT Beta adds the first production increment of Inkstone's multilingual interface.

## Highlights

- Follow Obsidian's startup language for supported locales.
- Add Simplified Chinese translations for commands, notices, settings, Snapshot capture entry
  points, the quick annotation toolbar, and the annotation inspector.
- Keep English as the fallback for unsupported locales and missing translations.
- Add typed locale catalogs, catalog-parity checks, and focused UI integration tests.
- Preserve annotation and Ink persistence formats without migrations.

## Upgrade

BRAT should update the plugin from the GitHub Release automatically. To install it manually,
download `main.js`, `manifest.json`, and `styles.css` from this Release and replace the files under:

```text
<Vault>/.obsidian/plugins/inkstone-annotations/
```

Reload Obsidian after the files are updated. Back up the Vault before using a Beta with important
notes. Upgrading, disabling, or uninstalling the plugin does not remove canonical Sidecars or
exports.

## Compatibility

- Obsidian 1.7.2 or newer.
- Desktop and mobile manifests remain enabled.
- No Sidecar schema, data migration, telemetry, or external service changes.
- `html-to-image@1.11.13` remains embedded in `main.js`.

## Known limitations

- This release localizes the I0-I3 core annotation surfaces, not the entire plugin.
- Annotation sidebars and Ink/Snapshot editor toolbars still contain English copy.
- Built-in style display names remain English pending the preset-label policy.
- Text annotation creation remains limited to Reading View.
- Snapshot capture remains viewport-based rather than full-document capture.

See
[Data Safety](https://github.com/ivan-94/obsidian-plugin-ink-annotation/blob/main/docs/data-safety.md),
[Known Limitations](https://github.com/ivan-94/obsidian-plugin-ink-annotation/blob/main/docs/known-limitations.md),
